## How each number is computed

- **Retrieval** compares document titles. Each document counts once, at the position where it first appears. Simple mode's ranking is its hybrid search for the question (top 8 chunks); agent mode's is every document its searches returned, in the order it saw them.
- **Recall@5**: share of the gold documents among the first 5 documents. **Evidence recall**: the same over every document the mode saw, which is where extra agent searches can help. **MRR**: 1 / rank of the first gold document within the first 8, averaged.
- **Citation accuracy**: of the documents an answer cites, the share that are gold (or also state the fact, for NovaPay questions). Answers that cite nothing are not scored, so the Scored column can differ.
- **Exact match / Token F1** use SQuAD-style normalization after removing the [S#] markers. The answers are full sentences, so exact match is close to 0 by design; **Gold answer in the answer** checks whether the normalized gold answer appears in the answer as whole words.
- **Abstained** means status `insufficient`. **Reported a conflict** means the `conflicts` list is not empty; whether it is the right conflict is graded by hand.
- **error** means the LLM call failed even after retries; it counts as a wrong answer, and agent-mode errors have no retrieval scores because their search trace was lost.
